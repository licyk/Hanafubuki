    INSTALLER

    安装包

    把 Hanafubuki 装进系统，之后从桌面或开始菜单直接打开，新版本由应用自己检查和升级。

    • 安装到系统安装后出现在桌面与开始菜单，像其他桌面应用一样启动和卸载。
    • 内置签名更新应用会核对 ModelScope 与 Hugging Face 两个来源，确认新版本后可直接升级。
    • 各平台原生格式Windows 提供 exe 与 MSI，macOS 提供 dmg，Linux 提供 AppImage、deb 与 rpm。
    • 适合长期使用只想在这台机器上稳定使用 Hanafubuki，从安装包开始最省事。

    两种版本，选择其中一种

    PORTABLE

    便携版

    解压就能用的 Launcher，把 Hanafubuki 和它的数据都留在同一个文件夹里，适合移动硬盘或多份互不干扰的环境。

    • 不写入系统设置、日志与实例数据都保存在程序旁的 .hanafubuki-launcher 目录里，随盘带走。
    • 自动准备应用本体Launcher 按清单下载、校验并在损坏时修复 Hanafubuki 本体，不需要另外安装。
    • 就地发现 WebUI首次运行会扫描所在目录，把放在旁边的 WebUI 目录直接接管为实例。
    • 断网也能启动更新源都不可用时跳过远程检查，直接用已下载的版本启动。
