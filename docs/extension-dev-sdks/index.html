SDK

用 Rust SDK（hanafubuki-extension-sdk）或 Python SDK（hanafubuki_extension）编写扩展后端，附最小示例。

两个 SDK 都实现了后端协议的通信部分：读写帧、回答 initialize 和 ping、在工作线程中处理常规请求，并提供调用宿主接口的 Host。后端只需要实现自己关心的方法。

标准输出属于协议

后端不能向标准输出写入协议以外的内容。Rust 中用 eprintln! 输出日志；Python SDK 会把 sys.stdout 重定向到标准错误，因此 print 会写入日志而不会破坏协议帧。

方法默认行为

initialize(host, params)回答协议版本 1 和 hooks()

两个 SDK 都在工作线程处理常规请求（包括 deactivate），可以在其中等待宿主调用返回。notification 和 shutdown 在读取回复的线程上运行，必须尽快返回。在通知中将需要宿主回复的工作交给其他线程，在 shutdown 中只完成本地清理。连接关闭后，等待中的调用和后续调用都会收到 UNAVAILABLE。

转义计划中的花括号

安装计划和启动计划都是模板，{ 和 } 会被当作占位符。路径、设置值等不是自己写的文本，放入计划前要把花括号加倍。

最小示例

launch_plan 用后端自己的解释器（应用受管的 Python）在实例的 core 组件中运行标准库的 http.server，install_plan 写入的页面就是它提供的内容。frame_call 中的 servers.status 需要 permissions.instances = "own-types"。ui_state 就是界面状态：写了 "source": "state" 和 "path": "visits" 的面板块显示它，每次点击面板操作都会推送新状态。

不使用 SDK

后端也可以用任何语言直接实现协议：按 协议概要 的分帧读写 JSON-RPC 消息，回答 initialize（protocolVersion 为 1，hooks 为实现的钩子）、ping 和 shutdown。每个方法及其参数见接口参考和后端协议参考。

网络调用与单次进程代理

Rust 使用 Host::http_request(&HttpRequestParams)、download_fetch(&DownloadFetchParams)、process_run(&ProcessRunParams)；类型由 protocol 重导出。Python 的同名方法使用 hanafubuki_extension.protocol 中的 typed dict 参数和结果。省略可选字段可使用宿主默认值；SDK 不复制宿主校验。

例子要求 manifest 声明源主机的 network 权限及 processes = true。HTTP 错误状态由调用者处理；RPC 错误通过 RpcError 返回。下载的 sha256 不应从同一次不可信下载中反推；无摘要时 cache 不产生可复用命中。方法字段、默认值、权限及限制见生成接口参考。

自身设置

Rust 用 host.settings() 读取，用 host.settings_patch(&SettingsPatchParams { patch }) 写入。Python 用 host.settings_get() 和 host.settings_patch({"patch": {...}})。两者都返回 {values}。不接受扩展 ID，也不需要额外权限：宿主将调用者绑定到自己的设置。

None（传输中的 null）取消保存的覆盖，恢复声明的默认值。未知设置 key 或无效值使整个 patch 失败；保存失败不发布成功事件。成功后返回 canonical values，若本后端订阅了 settings，则收到一次设置事件。应用设置页、后端与自定义 frame 使用同一套 Rust 校验和存储。值可能包含密钥，不要记录到日志。自定义 frame 使用 getSettings() 与 patchSettings(patch)，没有后端也可用。

宿主偏好快照

Rust 使用 host.host_preferences() -> Result<HostPreferences, RpcError>；Python 使用 host.host_preferences() -> HostPreferences。HostPreferences 也是 preferences 事件的 data 类型。这是只读投影；自定义 frame 继续使用已有 theme/locale 通知。

通知 handler 应快速返回，不在其中调用宿主。代理配置变化可能发出公开内容相同的快照；后续宿主网络调用使用最新策略。Python SDK 的 hanafubuki_extension.protocol 还提供 PreferencesEvent、HostNetworkPreferences 和镜像类型。可选 instancesDir 与 mirrors 可能为 None；快照不提供代理凭据。

Frame 宿主操作与声明式 Agent 内容

frame SDK 提供 openSettings(section: string): Promise<void> 与 openExternal(url: string): Promise<void>，分别封装 open-settings 和 open-external 宿主请求。未知 section、无效 URL 或宿主错误都会以 FrameError 结束 Promise，见 frame 示例。

Agent Skills/MCP 属于 manifest 贡献，不是写 Agent 配置的后端 SDK 方法。宿主把声明适配为带命名空间的 linked Agent package，并让其生命周期跟随扩展，见 Agent 贡献。Rust/Python 后端可通过 settings.patch 修改 {setting: "key"} 引用的自身已声明字符串设置；成功保存会刷新宿主管理的贡献。

生成的 UI 声明还包含 frame 安全动效工具及关联类型。使用 Vue h 渲染泛型组件时，应显式实例化组件，例如 NavList<Item>，以保留条目 props、事件值和 slot payload 之间的类型关系；不要假设 h 能自动推断所有泛型关联。可执行动效示例 严格对照 sdk/ui/ui.d.ts（见上面的视图类型声明）检查，网站展示的正是 linked gallery 运行的同一份源码。
